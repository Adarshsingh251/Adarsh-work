# 🛒 Online Shopping UI Clone (Flipkart Style)

A modern responsive e-commerce front-end project inspired by Flipkart.  
Built using HTML, CSS, JavaScript, and Swiper.js to create a dynamic shopping interface.

---

## 🚀 Features

-  Login / Sign In Popup
-  Search Bar UI
-  Product Category Slider
-  Multiple Swiper Carousels
-  Fully Responsive Design (Mobile, Tablet, Desktop)
-  User Login → Sign Out Toggle UI
-  Cart Section UI
-  Seller Section UI
-  Clean and Modern Layout
-  Footer with Useful Links

---

## 🧑‍💻 Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Swiper.js
- Font Awesome
